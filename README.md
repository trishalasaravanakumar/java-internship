## Completed Tasks

### Task 1 – Number Guessing Game
A console-based game where the user guesses a randomly generated number.

**Features:**
- Random number generation
- User input
- Higher/Lower hints
- Attempt counter
- Result display

### Task 3 – Library Management System
A console-based system for managing library books.

**Features:**
- Add books
- Remove books
- Display available books
- Search books by ID or title
- Issue books
- Return books

### Task 5 – Employee Payroll System
A system for calculating and managing employee salaries.

**Features:**
- Add employee records
- Salary calculation
- Tax calculation
- Deduction calculation
- Salary slip generation
- Employee record storage

### Task 6 – Online Quiz Application
A multiple-choice quiz application with score calculation.

**Features:**
- Multiple-choice questions
- User answer input
- Score calculation
- Correct and wrong answer count
- Final result evaluation
